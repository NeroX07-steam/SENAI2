CODESTUDY — CENTRAL DE PROGRAMAÇÃO

Arquivos:
- index.html
- style.css
- script.js

Como usar:
1. Extraia os arquivos.
2. Abra index.html no navegador.
3. Escolha o perfil.
4. Estude as linguagens, faça exercícios e quizzes.

Perfis:
- Luiz: explicações diretas
- Julya: explicações simples, estilo iniciante
- Nairelis: explicações detalhadas

Recursos:
- Escolha de perfil ao abrir
- Progresso separado por perfil
- LocalStorage
- HTML, CSS, JavaScript, Python, C++, Java e SQL
- Estudo separado das aulas
- Conceitos e exemplos de código
- Exercícios com respostas aceitas e botão Mostrar resposta
- Quiz de 10 perguntas
- XP
- Conquistas
- Níveis 1, 2 e 3
- Pesquisa
- Tema claro/escuro
- Layout responsivo

Observação:
O site funciona localmente sem servidor. Para publicar, envie os três arquivos para GitHub e Vercel.
