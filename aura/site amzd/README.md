# Site de Amizade — Eu & Julya 💗

Site feito com HTML, CSS e JavaScript puro.

## Arquivos

- `index.html` — estrutura do site
- `style.css` — visual e responsividade
- `script.js` — contador, menu e interações

## Como usar

Abra o arquivo `index.html` no navegador.

## Como colocar a data exata

No `script.js`, procure:

```js
const dataConhecemos = null;
```

Troque pelo dia correto. Exemplo:

```js
const dataConhecemos = new Date("2026-04-15T00:00:00");
```

Também pode alterar textos, emojis e mensagens diretamente no `index.html`.

## Vercel / GitHub

Basta enviar os três arquivos para um repositório do GitHub e importar o repositório na Vercel. Não precisa de framework ou build.
